What this model computes

  1. 01 · MODEL THE TUMBLE

    A rigid body with three different moments of inertia

    The numerical model integrates rigid-body Euler equations for ω, with a quaternion attitude q. Angular velocity uses RK4 while torque is held fixed within each step. Quaternion updates are normalized. The body dimensions and inertias are illustrative model inputs, not measured spacecraft values.

    Iω˙+ω×(Iω)=τq˙=12q⊗[0,ω]
  2. 02 · FIND THE FIXED ARROW

    Angular momentum doesn't wander

    In the ideal torque-free equations, angular momentum H is fixed in an inertial frame. Here the planner scores candidate positions by the torque component opposing the estimated H. It does not compute the receiving spacecraft’s reaction dynamics.

    H=R(q)IωdHdt=τ
  3. 03 · SEE IT

    Synthetic attitude observations

    At 15 samples per model second, the code takes the model’s true attitude and adds seeded noise to produce q̃. A filter predicts and corrects attitude and spin. The inset is a rendered camera view with synthetic feature markers; it does not run image-based feature detection or pose solving. Loss of model lock disables commanded sweep while arm positioning continues.

    δθ=2vec(q^−1⊗q~) q^←q^⊗exp(αδθ),ω^←ω^+βΔtδθ
  4. 04 · DECIDE WHERE, BY PREDICTION

    Score a short model prediction

    The planner samples 260 directions, excludes directions on the far side, and scores the rest against a 1.5-model-second torque-free attitude prediction. Reach and position-change weights affect the score, refreshed every 0.4 model seconds. The keep-out sphere uses the box dimensions; protrusions and the full arm are not collision checked. The arm is a geometric two-link rendering, not a constrained robot IK or actuator simulation.

    S(d)=−H^·∑k=115τ(d;q^k,ω^k)Δt×w(d)
  5. 05 · BRAKE WITHOUT CONTACT

    Phenomenological local-patch drag

    The code chooses the closest clamped point on the box hull, applies a gap-dependent drag to relative tangential velocity, and takes its moment about the center of mass. This is a phenomenological local-patch model. It does not solve electromagnetic fields, current distributions, conductivity, skin depth, magnet dimensions or thermal response. The glow indicates a model quantity; it is not a solved eddy-current image.

    vrel=ω×rp−vfF=−kB(g)2[vrel−(vrel·e^)e^] τ=rp×FB(g)=B0(aa+g)3
  6. 06 · COMMAND A MODEL SWEEP

    A commanded sweep and schematic magnet

    In spinning mode, the controller commands a local field-velocity proxy opposite the estimated hull motion, limited by G = 2.5 and the model speed cap. The red/blue magnet is drawn as diametric poles rotating around its shaft. Its visible angle is schematic and does not enter the torque calculation. The expression below is conditional on this local drag approximation; arbitrary magnet rotation does not always brake a target.

    vf=−su^t,s=min(smax,G|vt|) dTdt=F·vt=−kB2|vt|2(1+Gcosφ)<0whencosφ>−1G
Model assumptions
  • All rates, lengths, energies, durations and thresholds shown here are simulated outputs from illustrative inputs. The export describes scaled braking strength. No real stopping time, efficacy or measured performance is established.
  • The spacecraft holds a fixed position. Spacecraft reaction, thermal effects and orbital motion are not modeled. Detumbling does not remove an object from orbit.
  • The estimator uses deliberately perturbed inertia inputs and true model attitude plus noise. This does not establish real camera accuracy or AI performance.
  • The threshold uses filtered estimated spin, not a verified physical capture criterion. Passive model drag remains while the controller is in standby or the commanded sweep is zero.
  • This browser model includes pause/replay, responsive view fitting and interactive orbit, zoom and target-spin controls.
